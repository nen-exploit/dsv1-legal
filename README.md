## Data requests and contact

To ask for access to, correction of, or deletion of data held by the bot, [open a data request](https://github.com/nen-exploit/dsv1-legal/issues/new?template=data-request.yml). GitHub issues are public, so do not include passwords, tokens, private messages, or other sensitive information. If you need a private way to provide details, ask through the contact options on the [operator's GitHub profile](https://github.com/nen-exploit).

The published pages are maintained in `index.html`, `terms.html`, and `privacy.html` in this repository.
